# Credit Scoring Model

## 📌 Project Overview

This project develops a machine learning based Credit Scoring Model to predict the creditworthiness of loan applicants using historical financial and applicant information.

The project compares three classification algorithms:

* Logistic Regression
* Decision Tree
* Random Forest

The models are evaluated using Accuracy, Precision, Recall, F1-Score, and ROC-AUC.

## 🎯 Objective

The objective of this project is to build a classification model that can predict loan status based on applicant information and compare different machine learning algorithms.
